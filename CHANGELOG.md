# Changelog – TechFix Solutions

## [Part 2] 

### Added
- External CSS file (`css/style.css`) linked on all pages
- Flexbox layouts for header, navigation, cards, and hero
- CSS Grid for services, about (mission/vision), and gallery
- Media queries for tablet (max-width: 768px) and mobile (max-width: 480px)
- Pseudo-classes: :hover, :focus, :focus-visible, :active
- Pseudo-elements: ::before (heading accent, card top bar), ::after (nav underline)
- Google Fonts: Outfit (headings) and Plus Jakarta Sans (body)
- Active navigation state (class="active")
- Responsive image rules (max-width, aspect-ratio)

- Hero section rebuilt as a flex layout (text + image)
- Services page converted from stacked sections to a grid of service cards
- About page: mission and vision side-by-side with Grid
- Consistent spacing, shadows, and border-radius across all pages
